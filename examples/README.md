# Демонстрационные данные

| Файл | Как использовать | Что показывает |
|---|---|---|
| `scores-demo.csv` | «Порог» → «Свои оценки (CSV)» → загрузить | 20 000 синтетических оценок (seed 42) из распределений статьи СРО1: N(0,72; 0,09) и N(0,30; 0,11). Эмпирический оптимум близок к аналитическому τ* = 0,5818 |
| `catalog-10-factors.json` | `POST /api/v1/factor-catalogs` (Swagger) или вставить факторы в таблицу | Задача с 10 факторами (1023 набора): ЦЛП и полный перебор дают одинаковый результат |
| `infeasible.json` | `POST /api/v1/factor-selection/solve` | Слишком жёсткие ограничения: ответ 422 с диагностикой, какое ограничение мешает чаще всего |

Загрузка каталога из командной строки:
```bash
curl -X POST http://localhost:4000/api/v1/factor-catalogs -H 'content-type: application/json' --data @examples/catalog-10-factors.json
```
