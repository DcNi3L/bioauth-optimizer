# BioAuth Optimizer

Программное средство оптимизации параметров биометрической аутентификации.
СРО2 по дисциплине «Методы и инструменты оптимизации», Университет «Туран».
Автор: **Мекенбаев Даниэль Кайратханович**, магистрант ОП «Информационные системы».

Система реализует методы из статьи СРО1 «Многокритериальная оптимизация параметров систем биометрической аутентификации»:

| Модуль | Метод СРО1 | Результат |
| --- | --- | --- |
| Оптимальный порог | Минимум байесовской стоимости `E(τ) = cFA·FAR(τ) + cFR·FRR(τ)` (формула 1) | τ* против точки равных ошибок, выигрыш в %, графики FAR/FRR/E и ROC |
| Состав факторов | Целочисленное программирование с правилом «И» (формулы 2–3) | Оптимальный набор, рейтинг допустимых наборов, анализ чувствительности к бюджету |

Модельный пример статьи воспроизводится точно и закреплён тестами: τ_EER = 0,531, τ* = 0,5818, снижение потерь 41,8 %; 6 допустимых наборов из 31, оптимум F2+F5, при бюджете 2,0 — F1+F2.

## Запуск

```bash
docker compose up --build
```

Интерфейс — <http://localhost:3000>, Swagger — <http://localhost:4000/api/docs>.

Разработка: `pnpm install && pnpm test` (Node.js 22, pnpm 10).

## Проверка качества

| Уровень | Что проверяется | Тестов |
| --- | --- | --- |
| Ядро (Vitest) | числа статьи СРО1, 50 эталонов SciPy, хвосты до 10⁻¹⁹⁸, property-тесты: согласие полного перебора и ЦЛП на случайных задачах, регрессии | 103 |
| API (Jest) | use cases с заглушками портов, CSV-парсер, e2e всех эндпоинтов на реальном PostgreSQL | 16 |
| Фронтенд (Vitest) | форматирование и разбор чисел | 12 |
| Контракты (Vitest) | zod-схемы запросов | 5 |
| E2E (Playwright) | сценарии в браузере против `docker compose up` | 4 |

CI (GitHub Actions) на каждый push: типы, все тесты, линтер FSD (steiger), сборка Docker-образов, запуск compose и e2e.

## Структура

```plaintext
apps/api                     NestJS — REST API (Clean Architecture)

packages/contracts           zod-схемы, общие для api и web
docs/                        требования, математическая модель, архитектура, ADR, диаграммы
```
