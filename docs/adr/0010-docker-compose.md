# ADR-0010. Развёртывание через Docker Compose

**Статус:** Принято · **Дата:** 04.11.2026

## Контекст
Программу должны запустить преподаватель и комиссия на своей машине без настройки окружения.

## Решение
`docker compose up --build` поднимает `db`, `api`, `web` (06-deployment). Многоэтапные образы с `turbo prune`, непривилегированный пользователь, healthcheck'и и `depends_on: service_healthy`, автоматические миграции и seed при старте `api`. Данные — в именованном томе `pgdata`.

## Альтернативы
- *Kubernetes / Helm* — несоразмерно задаче. Отклонено.
- *Ручной запуск через pnpm* — оставлен для разработки, но не как основной способ запуска.

## Последствия
- (+) Запуск одной командой на Windows, macOS и Linux.
- (−) Нужен установленный Docker Desktop; на защите стоит иметь заранее собранные образы.
