# ADR-0006. Порог: аналитическое решение + численная верификация; эмпирический режим — точный перебор

**Статус:** Принято · **Дата:** 04.11.2026

## Контекст
Формула (1) СРО1: E(τ) = cFA·FAR(τ) + cFR·FRR(τ) → min. Статья говорит: «при известных плотностях минимум достигается там, где отношение плотностей равно cFR/cFA; иначе порог подбирается по ROC-кривой». Нужны точность ≤ 10⁻⁹ и отсутствие ложных локальных минимумов.

## Решение
- **Нормальные распределения:** τ_EER — в замкнутой форме; τ* — корни квадратного уравнения из условия cFA·f_I = cFR·f_G (02 §2.1.1), сравнение кандидатов, включая вырожденные «допускать всех» / «отвергать всех». Затем **независимая проверка**: глобальная сетка и бисекция по производной E′, вычисленной напрямую через плотности; при расхождении > 10⁻⁷ результат помечается и логируется.
- **Эмпирические оценки:** E кусочно-постоянна, поэтому точный минимум даёт проход двумя указателями по всем уникальным значениям (O(n log n)). Возвращается интервал оптимальных порогов и его середина.
- Ограничение FAR ≤ FAR_max переводится в нижнюю границу порога через `erfcinv`.

## Альтернативы
- *Только численная оптимизация (Brent, золотое сечение)* — E(τ) может иметь два стационарных значения, а локальный метод найдёт не тот. Отклонено как основной метод; сетка + бисекция по E′ оставлены как верификатор.
- *Сеточный поиск* — точность ограничена шагом. Отклонено.
- *Сглаживание эмпирических данных (KDE)* — меняет постановку и вводит параметр полосы. Отклонено для v1.

## Последствия
- (+) Глобальный оптимум гарантирован для гауссовой модели; результат воспроизводим.
- (+) Эмпирический режим точен на данных пользователя, без аппроксимаций.
- (−) Другие параметрические семейства (бета, лог-нормальное) потребуют своей реализации `ScoreModel` и оптимизатора — точка расширения предусмотрена (OCP).
