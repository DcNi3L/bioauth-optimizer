# ADR-0019. Справочник API — Scalar вместо Swagger UI

**Статус:** Принято · **Дата:** 05.11.2026

## Контекст

Спецификация OpenAPI генерируется из zod-контрактов через `@nestjs/swagger` (ADR-0009), а справочник показывал Swagger UI.
К версии 3 API вырос до 25 групп и ~100 операций, плюс конечные точки OpenID Connect: в Swagger UI трудно искать,
примеры запросов есть только в виде curl, тёмной темы нет. Справочник должен работать и без интернета — защита
проходит на ноутбуке в режиме `make up-offline`.

## Решение

1. Справочник — **Scalar** (`@scalar/api-reference`), страница `GET /api/docs`: поиск (Ctrl/⌘ K), навигация по тегам,
   примеры на curl, JavaScript, Python и других языках, отправка тестового запроса, светлая и тёмная темы в цветах
   интерфейса BioAuth.
2. Генерация спецификации не меняется: `@nestjs/swagger` (`DocumentBuilder`, декораторы `ApiZodBody`/`ApiZodOk`).
   Спецификация — `GET /api/openapi.json`; прежний адрес `/api/docs-json` сохранён для совместимости.
3. Сборка Scalar (`dist/browser/standalone.js`) раздаётся самим api с `/api/docs/assets/` — без CDN; внешние шрифты,
   телеметрия, ИИ-ассистент и облачные функции (генерация SDK, MCP) отключены. e2e-тест проверяет, что страница не
   ссылается на внешние адреса.
4. HTML страницы формируется в `bootstrap.ts`; обёртка `@scalar/nestjs-api-reference` не используется — она
   подключает ESM-пакет, который не загружается в Jest, а её единственная функция — шаблон из десяти строк.

## Альтернативы

- _Оставить Swagger UI_ — привычен, но уступает в поиске и примерах. Отклонено.
- _Redoc_ — только чтение, без отправки запросов. Отклонено.
- _Scalar с CDN_ — проще, но не работает без интернета. Отклонено.

## Последствия

- (+) Удобный справочник, работающий офлайн; спецификация и контракты не изменились.
- (+) Ссылка «Документация API (Scalar)» в боковой панели интерфейса (`NEXT_PUBLIC_API_DOCS_URL`).
- (−) +4,6 МБ статического JavaScript в образе api; версия Scalar закреплена и обновляется вручную.
