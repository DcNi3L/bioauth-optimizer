# ADR-0024. Проверка по голосу: исследование и решение (#38)

**Статус:** Отклонено для v3.3 · **Дата:** 13.11.2026

## Вопрос

Стоит ли добавить вход по голосу: диктор произносит случайную фразу-вызов, система сравнивает голос с шаблоном и
проверяет, что звучит живой человек, а не запись или синтез.

## Что известно

| Аспект         | Факты                                                                                                                                                                                                 | Вывод для BioAuth                                                                                                         |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| Модель диктора | ECAPA-TDNN (SpeechBrain, `spkrec-ecapa-voxceleb`): EER 0,8 % на VoxCeleb1-test, лицензия Apache 2.0, вход 16 кГц, есть экспорт в ONNX                                                                 | Модель и лицензия подходят; запуск в bio-engine через onnxruntime так же, как SFace                                       |
| Короткие фразы | 0,8 % получено на записях VoxCeleb длиной в несколько секунд и больше. Для фразы-вызова в 2–3 секунды и записи с микрофона ноутбука в браузере (шум, эхо, обработка звука) ошибка заметно выше        | Порог пришлось бы калибровать на своих данных, как для лица; на 20–30 участниках FAR ≤ 10⁻³ не подтвердить (правило трёх) |
| Подделки       | ASVspoof 5 (2024): у базовых детекторов (RawNet2, AASIST) EER выше 29 %. Лучшие закрытые системы — около 8,6–10 %, открытые на самообучаемых моделях — около 2,6 %; калибровка оценок у многих плохая | Синтез голоса по нескольким секундам записи доступен любому, а надёжного детектора подделок малого размера нет            |
| Фраза-вызов    | Случайная фраза защищает от воспроизведения готовой записи, но не от синтеза в реальном времени; распознавание фразы требует ещё одной модели (ASR) на трёх языках                                    | Сложность растёт вдвое: диктор + ASR (ru/kk/en) + детектор подделок                                                       |
| Данные         | Голос — биометрические персональные данные: нужна новая редакция согласия и отдельный протокол испытаний                                                                                              | Дополнительные требования к испытаниям СРО2                                                                               |

## Решение

В v3.3 голос **не добавлять**. Вход без камеры уже обеспечивают политики с шагами «код из приложения», «ритм набора» и
«passkey» (ADR-0022). Против подделок у голоса сейчас нет решения с проверяемой ошибкой. Оптимизатор состава факторов
выбрал бы голос только при заявленных, а не измеренных FAR/FRR, а это противоречит замкнутому контуру калибровки.

## Когда вернуться

- В бесплатном доступе появится компактный детектор подделок с EER ≤ 5 % на ASVspoof 5 и откалиброванными оценками.
- Понадобится вход без рук и без экрана (доступность): тогда голос — дополнительный шаг вместе с владением устройством,
  но не единственный.
- Порядок работ: экспорт ECAPA-TDNN в ONNX → режим «только сбор оценок» без влияния на вход → калибровка порога →
  шаг политики.
