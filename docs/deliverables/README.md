# Материалы для сдачи СРО2

| Файл                                                      | Содержание                                                                                                                                                       |
| --------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Техническое_описание_BioAuth_Optimizer.docx` (+ PDF)     | Назначение, математическая модель, алгоритмы, архитектура, данные и API, развёртывание, тестирование, связь с СРО1, версия 2 (живая биометрия, замкнутый контур) |
| `Руководство_пользователя_BioAuth_Optimizer.docx` (+ PDF) | Установка и запуск, расчёт порога, выбор состава факторов, история, экспорт, регистрация и вход по лицу, администрирование, ошибки, вопросы                      |
| `screenshots/`                                            | Снимки экранов версии 1 на данных примера СРО1 (используются в документах и презентации)                                                                         |
| `screenshots/v2/`                                         | Снимки экранов версии 2: регистрация, вход, рабочее место администратора                                                                                         |

Оглавление в .docx заполнено; после правок в Word обновите его: правой кнопкой по оглавлению → «Обновить поле» → «Обновить целиком».
