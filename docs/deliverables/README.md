# Материалы для сдачи СРО2

| Файл                                                      | Содержание                                                                                                                                                                                                                              |
| --------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Техническое_описание_BioAuth_Optimizer.docx` (+ PDF)     | Назначение, математическая модель, алгоритмы, архитектура, данные и API, развёртывание, тестирование, связь с СРО1, версия 2 (живая биометрия, замкнутый контур), версия 3 (сервер авторизации OIDC, учётные записи, админ-панель, PWA) |
| `Руководство_пользователя_BioAuth_Optimizer.docx` (+ PDF) | Установка и запуск, расчёт порога, выбор состава факторов, история, экспорт, регистрация и вход по лицу, профиль, админ-панель, вход в приложения через OIDC, язык и тема, PWA, ошибки                                                  |
| `Презентация_СРО2.pptx` (+ PDF)                           | 12 слайдов для защиты (около 7 минут), заметки докладчика с таймингом                                                                                                                                                                   |
| `screenshots/`                                            | Снимки экранов версии 1 на данных примера СРО1 (используются в документах и презентации)                                                                                                                                                |
| `screenshots/v3/`                                         | Снимки экранов версии 3: оболочка, «Алгоритм», профиль, админ-панель, OIDC, тёмная тема, телефон (лицо на кадрах камеры размыто)                                                                                                        |
| `screenshots/v2/`                                         | Снимки экранов версии 2: регистрация, вход, рабочее место администратора (лицо на кадрах камеры размыто)                                                                                                                                |

Оглавление в .docx заполнено; после правок в Word обновите его: правой кнопкой по оглавлению → «Обновить поле» → «Обновить целиком».
