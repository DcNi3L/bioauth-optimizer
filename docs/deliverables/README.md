| --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `Техническое_описание_BioAuth_Optimizer.docx` (+ PDF)     | Назначение, математическая модель, алгоритмы, архитектура, данные и API, развёртывание, тестирование, связь с СРО1 |
