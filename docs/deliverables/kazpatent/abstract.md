# Реферат программы для ЭВМ

**Название:** BioAuth Optimizer — программное средство многокритериальной оптимизации параметров систем
биометрической аутентификации.

**Автор:** Мекенбаев Даниэль Кайратханович.

**Год создания:** 2026.

## Назначение

Программа предназначена для обоснованного выбора параметров систем биометрической аутентификации: порога принятия
решения и состава факторов. Она же является действующим сервером аутентификации, на котором выбранные параметры
применяются и проверяются на реальных попытках входа.

## Область применения

Проектирование и эксплуатация систем контроля доступа и удалённой идентификации; учебные и исследовательские работы
по биометрии и информационной безопасности.

## Функциональные возможности

1. Расчёт оптимального порога по минимуму ожидаемой стоимости ошибок E(τ) = c_FA·P_imp·FAR(τ) + c_FR·P_gen·FRR(τ)
   для нормальных распределений оценок (аналитически, с численной проверкой) и для эмпирических данных (точный
   перебор), с ограничением на FAR; построение кривых FAR, FRR, стоимости и ROC.
2. Выбор состава факторов аутентификации при ограничениях на бюджет, задержку, FAR и наличие защиты от атак
   предъявления: полный перебор и целочисленное линейное программирование с проверкой оптимальности; анализ
   чувствительности к бюджету.
3. Регистрация и вход по лицу с активной проверкой «живости» (случайные команды) и пассивным обнаружением атак
   предъявления; вход по passkey (WebAuthn).
4. Калибровка порогов по накопленным оценкам реальных попыток, версии политики входа с утверждением вторым
   администратором, контроль дрейфа, протокол испытаний с доверительными интервалами.
5. Сервер авторизации OpenID Connect (Authorization Code с PKCE, refresh-токены с ротацией), учётные записи,
   сессии, журнал аудита с контролем целостности, панель администратора.

## Состав и язык

Вычислительное ядро (`optimization-core`), контракты данных, серверное приложение и веб-интерфейс — TypeScript
(Node.js 22, NestJS, Next.js, React); сервис обработки изображений лица — Python 3.12 (FastAPI, OpenCV, ONNX).
Хранение данных — PostgreSQL 16. Депонируемый фрагмент — исходный текст вычислительного ядра.

## Требования к ЭВМ и программному окружению

Процессор x86-64 или ARM64; рекомендуется оперативная память от 4 ГБ и 5 ГБ свободного места на диске. Операционная система
Linux, macOS или Windows с Docker Engine 24 и Docker Compose 2 либо Node.js 22, Python 3.12 и PostgreSQL 16.
Для входа по лицу — веб-камера; браузер Chrome, Edge, Firefox или Safari актуальной версии.
