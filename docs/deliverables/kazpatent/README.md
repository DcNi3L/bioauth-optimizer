# Материалы для регистрации программы для ЭВМ (Казпатент)

Заготовки для заявки на внесение сведений в Государственный реестр прав на объекты, охраняемые авторским правом
(issue #7). Подача и оплата выполняются автором лично через портал Национального института интеллектуальной
собственности или eGov — из репозитория это сделать нельзя.

| Файл                                                           | Назначение                                                            |
| -------------------------------------------------------------- | --------------------------------------------------------------------- |
| [abstract.md](abstract.md)                                     | Реферат программы: назначение, функции, язык, объём, требования к ЭВМ |
| [listing-optimization-core.txt](listing-optimization-core.txt) | Исходный текст вычислительного ядра с нумерацией строк                |

Листинг пересобирается командой `make kazpatent-listing` — делайте это на коммите выпуска, который указываете в заявке.

## Перед подачей

Порядок, перечень документов и размер оплаты меняются — **проверьте их на официальном сайте в день подачи**, а не
по этому файлу.

- [ ] Уточнить действующий перечень документов, формат депонируемых материалов (объём листинга, PDF или текст) и оплату.
- [ ] Согласовать с научным руководителем: нужен ли соавтор и указывается ли университет как правообладатель.
- [ ] Заполнить заявление. Название: «BioAuth Optimizer — программное средство многокритериальной оптимизации
      параметров систем биометрической аутентификации». Автор: Мекенбаев Даниэль Кайратханович.
- [ ] Приложить реферат и листинг (при необходимости — сократить листинг до требуемого объёма: первые и последние страницы).
- [ ] Оплатить, подать, сохранить номер и дату заявки.
- [ ] Подтверждение подачи или свидетельство приложить к сдаче в Canvas.

Сканы заявления, квитанции и свидетельства содержат персональные данные (ИИН, адрес) — **в репозиторий их не кладите**.
