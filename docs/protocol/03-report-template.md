# Раздел отчёта: испытание калибровки на живых данных

> Шаблон для диссертации и статьи. Числа берутся из CSV страницы «Протокол» и JSON эксперимента калибровки;
> в тексте указывается идентификатор эксперимента, чтобы расчёт можно было повторить.

## Методика

**Участники.** N = ** добровольцев (** женщин, ** мужчин, возраст **–\_\_ лет), письменное информированное согласие.
Демографический состав и условия съёмки описываются явно: от них зависит переносимость результатов.

**Оборудование.** Ноутбук **\_\_**, встроенная камера \_**\_ (640×480), браузер \_\_\_\_**. Сервис распознавания:
YuNet 2023mar + SFace 2021dec (версия модели `sface-2021dec+yunet-2023mar`), PAD — MiniFASNet V2 + V1SE.

**Сбор.** На участника: 3 регистрационные попытки (по 5 кадров), 10 попыток входа в трёх условиях освещения.
Атаки (ISO/IEC 30107-3): печатное фото, фото на экране телефона, видео на мониторе — по 10 предъявлений на каждого из
10 участников.

**Оценки.** Genuine — пары кадров регистрации и успешные входы, подтверждённые вторым фактором; impostor —
перекрёстное сравнение пробы каждой попытки с шаблонами других участников (до 50 на попытку)
[и пакетный режим на наборе ______, лицензия ______].

**Расчёт.** Порог τ* — минимум E(τ) = cFA·FAR(τ) + cFR·FRR(τ) (формула (1) статьи СРО1) эмпирическим перебором ядра v1
при cFA = \_\_\_\_, cFR = \_\_\_\_. Интервалы — 95% Уилсона; подтверждённый FAR — правило трёх (3/n) при отсутствии ложных
допусков. «До» — исходный порог 0,363 (рекомендация OpenCV для SFace), «после» — откалиброванный τ\*; обе строки
считаются на одной выборке.

## Обсуждение и ограничения

- **Малая выборка.** При n_impostor = ** подтверждается лишь FAR ≤ **; утверждать FAR порядка 10⁻⁵ нельзя без пакетного
  режима на крупном наборе.
- **Оптимизм оценки.** Порог подобран и проверен на одних данных; для несмещённой оценки нужна отложенная выборка
  или перекрёстная проверка — указать, сделано ли это.
- **Состав участников.** Студенты одного вуза, узкий диапазон возраста и этнического состава; результаты могут не
  переноситься на другие группы.
- **Условия.** Одна модель камеры и три условия освещения.
- **Атаки.** Только атаки низкой стоимости (печать, экран, видео); маски и deepfake-инъекции не испытывались.
