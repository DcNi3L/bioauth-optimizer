## 8.3. Версия 2 (после сдачи, для диссертации)

- **Класс 1, ≥ 3 модальностей:** совместный выбор правила, весов и порога объединения метаэвристиками (PSO/GA) — новый модуль `fusion-optimization`, новая реализация `FusionRule` для «ИЛИ» и взвешенной суммы.
- **Многокритериальность:** фронт Парето (FRR, задержка, стоимость) при FAR ≤ FAR_max — NSGA-II или точный перебор недоминируемых наборов.
- **Класс 2:** байесовская оптимизация гиперпараметров (отдельный Python-воркер с Optuna). Здесь появится длительная задача, и тогда по ADR-0005 добавляется очередь (RabbitMQ) и статус задачи в БД.
