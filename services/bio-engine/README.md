# bio-engine

Внутренний сервис распознавания лиц без состояния и без доступа к БД (ADR-0012, docs/10 §10.5). Принимает кадры
JPEG/PNG в base64 и возвращает числа: проблемы качества, шаблон, оценку сходства, вероятность «живого» лица и
результат активных команд. Работает только во внутренней сети docker compose; все методы `/v1` требуют заголовок
`X-Bio-Secret`.

## Методы

| Метод                                    | Назначение                                                                                                  |
| ---------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| `POST /v1/face/analyze`                  | Детекция YuNet и контроль качества каждого кадра: одно лицо, размер, резкость, яркость, поза                |
| `POST /v1/face/template`                 | Шаблон регистрации по годным кадрам (≥ 3): нормированное среднее эмбеддингов SFace, genuine-оценки пар, PAD |
| `POST /v1/face/verify`                   | Медиана косинусного сходства кадров попытки с шаблоном, согласованность кадров, эмбеддинг пробы             |
| `POST /v1/face/liveness`                 | Пассивная PAD (MiniFASNet), 1–5 активных команд относительно нейтральных кадров, согласованность личности   |
| `POST /v1/batch/face?seed=&maxImpostor=` | Пакетный режим: zip «<субъект>/<файл>» → genuine- и impostor-оценки по протоколу пар с seed                 |
| `GET /health/live`, `/health/ready`      | Проверки здоровья (без секрета); ready возвращает версии моделей                                            |

Ошибки — `application/problem+json` с машинным кодом: `VALIDATION_ERROR`, `INVALID_IMAGE`, `TOO_MANY_FRAMES`,
`PAYLOAD_TOO_LARGE`, `NOT_ENOUGH_GOOD_FRAMES`, `INVALID_ARCHIVE`, `EMPTY_ARCHIVE`, `INVALID_LAYOUT`,
`TOO_MANY_FILES`, `FILE_TOO_LARGE`, `ARCHIVE_TOO_LARGE`, `NO_GENUINE_PAIRS`, `NO_IMPOSTOR_PAIRS`, `NO_USABLE_FRAMES`, `MODEL_VERSION_MISMATCH`, `UNAUTHORIZED`.
Контракт с api зафиксирован примерами в `packages/contracts/fixtures/bio-engine`: их проверяют и pydantic-схемы
сервиса, и zod-схемы api.

## Модели

| Модель                           | Назначение              | Лицензия   | Как попадает в образ                                                               |
| -------------------------------- | ----------------------- | ---------- | ---------------------------------------------------------------------------------- |
| YuNet 2023mar                    | Детекция лица и 5 точек | MIT        | Скачивается при сборке, SHA-256 из `models.lock.json`                              |
| SFace 2021dec                    | Эмбеддинг 128, косинус  | Apache-2.0 | Скачивается при сборке, SHA-256 из `models.lock.json`                              |
| MiniFASNet V2 (2.7) и V1SE (4.0) | Пассивная PAD, 80×80    | Apache-2.0 | В репозитории; конвертирован из опубликованных весов `tools/minifasnet/convert.py` |

Версия сравнителя (`sface-2021dec+yunet-2023mar`) пишется в каждый шаблон и каждую оценку: оценки разных версий
не смешиваются при калибровке.

## Активные команды

Проверяются по изменению относительно нейтральных кадров того же человека (изображение не зеркальное):

| Команда       | Мера                                                   | Порог по умолчанию |
| ------------- | ------------------------------------------------------ | ------------------ |
| `TURN_LEFT`   | Δ (x носа − x середины глаз) / межзрачковое расстояние | ≥ +0,12            |
| `TURN_RIGHT`  | то же со знаком минус                                  | ≥ +0,12            |
| `CHIN_UP`     | (глаза–нос)/(нос–рот) относительно исходного           | ≤ 0,85             |
| `MOVE_CLOSER` | межзрачковое расстояние относительно исходного         | ≥ 1,25             |

Метки времени кадров шага должны строго возрастать и укладываться в 15 с. Пороги задаются переменными окружения
`BIO_LIVENESS__*` и `BIO_QUALITY__*` (см. `app/config.py`).

**Ограничения.** Проверка не является сертифицированной PAD: виртуальная камера и глубокие подделки в браузере
полностью не устраняются (docs/10 §10.13). Фактическая устойчивость измеряется испытанием PAD (UC-8).

## Разработка

```bash
make bio-setup   # pip install -r requirements-dev.txt и модели
make test-bio    # ruff, mypy --strict, pytest (unit, контракт, модели на эталонных изображениях)
cd services/bio-engine && BIO_SECRET=dev uvicorn app.main:create_app --factory --port 8000
```

Эталонные изображения тестов — общественное достояние: портрет астронавта NASA Эйлин Коллинз и портрет
Грейс Хоппер (ВМС США).
