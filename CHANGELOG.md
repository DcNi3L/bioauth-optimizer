# Журнал изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).
Версия вычислительного ядра `@bioauth/optimization-core` указывается отдельно: в 2.0.0 ядро не менялось (1.0.0).

## [2.0.0] — 2026-11-05

Живая биометрия и замкнутый контур калибровки (ТЗ — `docs/10-live-biometrics-spec.md`).

### Добавлено

- **bio-engine** (Python 3.12, FastAPI, ONNX Runtime): детекция YuNet, эмбеддинг SFace, пассивная проверка «живости»
  MiniFASNet; контроль качества кадра; проверка активных команд по геометрии 5 опорных точек; модели закреплены
  по SHA-256; пакетный режим `POST /v1/batch/face` (протокол пар с seed).
- **Пользователи и доступ**: регистрация субъекта, вход сотрудника по паролю (scrypt), сессии в httpOnly cookie,
  роли `subject` / `admin` / `researcher` / `auditor`, двухфакторный вход сотрудников с passkey, защита от CSRF,
  блокировка после неудачных попыток; команда `pnpm --filter @bioauth/api staff` для создания сотрудников.
- **Биометрия**: согласие и его отзыв с удалением данных; регистрация лица по 5 кадрам; шаблоны AES-256-GCM
  с отменяемой проекцией и ротацией ключа (`rekey`); passkey (WebAuthn, платформенный аутентификатор).
- **Вход по политике**: nonce, три случайные команды, решение по правилу «И», второй шаг passkey; версии политики
  с предложением, утверждением (четыре глаза), отклонением и откатом.
- **Замкнутый контур**: калибровка τ_face и τ_pad ядром v1 с проверкой достаточности данных (правило трёх, Уилсон);
  измеренный каталог факторов; испытание PAD (APCER/BPCER, ISO/IEC 30107-3); проверка дрейфа FRR; журнал попыток;
  пакетный режим; отчёт протокола «до/после калибровки».
- **Журнал аудита** только на добавление с цепочкой SHA-256 и проверкой целостности.
- **Интерфейс**: страницы регистрации, входа и профиля; рабочее место сотрудника «Управление» (обзор, калибровка,
  политики, попытки, испытание PAD, пакетный режим, протокол, аудит).
- **Тесты**: pytest bio-engine (в том числе на настоящих моделях), контрактные примеры api ↔ bio-engine, e2e api v2,
  Playwright с поддельной камерой Chromium и виртуальным аутентификатором WebAuthn.
- **Документация**: ADR-0016 и ADR-0017, обновлённые docs/03–07, материалы протокола испытаний (`docs/protocol`),
  техническое описание, руководство пользователя и презентация версии 2.0.0; `make images-save` / `images-load` /
  `up-offline` для запуска без интернета.

### Не вошло

- Пакетная оценка изображений отпечатков (NBIS) — отложена (ADR-0013).
- Испытание на добровольцах по протоколу §10.11 проводится отдельно.

## 1.0.0 — 2026-11-04

### Добавлено

- Вычислительное ядро: оптимальный порог по минимуму E(τ) = c_FA·FAR + c_FR·FRR (аналитически для нормальной модели
  с численной проверкой и точным перебором по своим оценкам), выбор состава факторов полным перебором и
  целочисленным программированием (HiGHS) с сертификатом оптимальности, анализ чувствительности к бюджету.
- REST API на NestJS с zod-контрактами и Swagger, PostgreSQL (Kysely, SQL-миграции), история экспериментов,
  каталоги факторов, загрузка CSV с оценками.
- Интерфейс на Next.js (FSD): порог, состав факторов, история, экспорт JSON/CSV/PNG.
- Тесты: золотые тесты статьи СРО1, эталоны SciPy, property-тесты, e2e; CI GitHub Actions; Docker Compose.
